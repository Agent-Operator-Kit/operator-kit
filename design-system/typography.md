# Operator typography

Use self-hosted Inter Variable 4.1, with system sans fallback. Source: https://rsms.me/inter/ and bundled Inter-LICENSE.txt. Normal styles 400, 500 and 600 are bundled in one variable font.

| Role | Size / line height | Weight |
| --- | --- | --- |
| Task title | 22 / 30 px | 600 |
| Section | 16 / 22 px | 600 |
| Body and controls | 14 / 22 px | 400–500 |
| Reading | 14 / 23 px | 400 |
| Compact navigation and rows | 13 / 20 px | 400–500 |
| Metadata | 12 / 18 px | 400 |

Use sentence case. Title tracking −0.025em; normal tracking for body. Use tabular numerals for changing counts. Reserve system monospace for IDs, paths and code. Never make all task metadata monospace. Keep paragraphs within 65ch and use 24–32 px content padding.

These sizes are Operator choices. On 2026-09-22, computed CSS on the heading of Linear’s public AI page declared Inter Variable. The Mobbin WorkOS screenshot establishes visual typography only; it does not reveal its font file, source scale or weights.
