# Operator Kit V5.2

V5.2 keeps the simple V5.1 local dependency graph and adds an optional advisory
model selector for choosing a model and thinking level together.

## Highlights

- deterministic, policy-bounded model recommendations for one task;
- quality gates before total-token, latency, and cost optimization;
- expected tokens include retry and escalation risk;
- a read-only `setup-guide` for onboarding and migration inputs;
- inert examples, policy `off`, no live catalog, and no automatic application;
- offline replay against a fixed baseline, with no online self-learning; and
- plugin version `0.5.2` with project marker `5.2`.

## Compatibility

V5.1 projects update directly and preserve project-owned model-selection data.
V4 and signed V5 projects still complete the reviewed V5.1 local-graph
migration before the compatible V5.2 marker update.

## Safety boundary

Installing V5.2 never changes a lane or Codex chat model, dispatches work,
creates credentials, calls a provider, or trains a routing model. A user must
provide and review the catalog and policy, opt into `recommend` mode, and decide
whether to follow each recommendation.

See [Updating to Operator V5.2](../guides/operator-v5-2-migration.md) and
[Advisory model selection](../guides/operator-model-selection.md).
