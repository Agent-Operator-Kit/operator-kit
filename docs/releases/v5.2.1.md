# Operator Kit V5.2.1

V5.2.1 is a compatible V5.2 patch that lets Operator suggest a reviewable
model-selection policy starting point from explicit lane setup and structured
previous-run evidence.

## Highlights

- new deterministic `operator-model-select.sh suggest-from-history` command;
- evidence-ranked candidate shortlists by task class, requiring at least three
  outcomes with known acceptance;
- observed acceptance, validation, retry, escalation, handoff, correction,
  token, latency, and cost summaries without treating unknown values as zero;
- exact catalog resolution for provider, model, profile, and reasoning values;
- safe lane inspection that emits only command digests and explicit model or
  reasoning flags, never raw commands;
- precise blocking and review inputs when history, identity, availability,
  telemetry, policy limits, or preferences are missing; and
- plugin version `0.5.3` while the project marker remains `5.2`.

## Safety boundary

Suggestions are read-only and advisory. They write no files, apply no model or
reasoning setting, dispatch no work, perform no online learning, and always keep
the draft policy mode `off`. Operator must present the evidence and missing
inputs for human review. Raw chats and Markdown handoffs are not mined by the
deterministic command.

The published `v5.2` tag remains unchanged. This patch is released separately
so existing V5.2 installations can update without rewriting release history.
